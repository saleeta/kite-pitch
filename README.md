# Kite: pitch material

Kite is a drone studio you wear: fly and direct a camera drone from smart glasses, plan shots with waypoints, and publish and share the film without manual editing.

- `docs/` story, architecture, demo script, slides outline, Project Hub draft and 12 video-generation prompts (`VIDEO-PROMPTS.md`)
- `deck/project/` source of the slide deck (`deck.json`, `deck.css`, `slides/*.html`)
- `assets/` concept hero image (AI-generated concept render)
